ETALASE DIGITAL STELLA - XI RPL (CRUD + Hak Akses)

CARA PAKAI (XAMPP)
1. Salin folder ini ke htdocs, misal: htdocs/Etalase Digital Stella
2. Buka phpMyAdmin > Import > pilih database/db_alumni.sql
3. Buka http://localhost/Etalase%20Digital%20Stella/login.php
4. Akun awal ada di bagian INSERT pada database/db_alumni.sql:
   super admin : superadmin / password
   admin       : admin / admin123
   siswa       : siswa / siswa123
   (ganti password setelah login pertama)

KONEKSI: ubah host/user/password di koneksi.php bila MySQL Anda berbeda.
